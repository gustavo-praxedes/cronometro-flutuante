## Before Any Visual Work

Commit to a clear aesthetic direction. Ask:
- What is the tone? (Pick one extreme — don't sit in the middle)
- What is the ONE thing someone will remember?
- What makes this unforgettable?

## Aesthetic Spectrum

```
Brutalist/Raw      ←————————————→  Luxury/Refined
Maximalist chaos   ←————————→      Severe minimalism
Retro-futuristic   ←——————————→    Organic/Natural
Editorial/Magazine ←————————→      Industrial/Utilitarian
Art Deco geometric ←——————————→    Playful/Toy-like
```

## Anti-AI-Slop Rules (Hard Stops)

```
❌ Purple gradients on white — #1 AI marker
❌ Centered layout with card grid → boring default
❌ Uniform rounded corners everywhere
❌ Inter / Roboto / System-ui as headline font
❌ Glow effects as primary affordance
❌ Evenly-distributed color palette (no hierarchy)
❌ Shadow that looks like: box-shadow: 0 4px 6px rgba(0,0,0,0.1)
❌ Cookie-cutter hero: big headline + subline + 2 buttons + mockup
```

## DFII Score — Before Executing Direction

```
Score = (Impact + Context Fit + Feasibility + Performance) − Consistency Risk

≥12 → Execute fully
8–11 → Proceed with discipline
4–7  → Reduce scope
≤3   → Rethink direction
```

## Core Principles

- **Bold intent**: every element placed with purpose
- **Typography as art**: headlines are design elements, not just text
- **Restraint OR maximalism**: both work — half-measures don't
- **Texture over flatness**: depth, grain, material, space
- **Color hierarchy**: dominant + accent (1 per view max)
