# Canvas Design Reference (Posters, Art, PDF/PNG)

## When to Use
User asks for: poster, art piece, static design, PDF/PNG visual, presentation cover, brand asset.

## 2-Step Process

### Step 1: Design Philosophy (.md)
Create a visual philosophy — not a layout, a worldview.

**Movement name**: 1–2 words ("Concrete Poetry", "Chromatic Silence", "Metabolist Dreams")

**Philosophy (4–6 paragraphs)**:
- How space and form manifest the idea
- Color and material character
- Scale and rhythm approach
- Composition and balance logic
- Visual hierarchy strategy

**Rules**:
- Each aspect mentioned once — no repetition
- Stress craftsmanship repeatedly: "meticulous", "painstaking", "master-level"
- Leave room for interpretive choices
- Generic enough to work anywhere (don't mention the subject)
- Output: `.md` file

### Step 2: Canvas Expression (.pdf or .png)
Express the philosophy visually. 90% design, 10% text.

**Quality standard**: museum or magazine quality — looks like countless hours of work by someone at the top of their field.

**Visual language**:
- Dense accumulation of marks OR vast silence
- Repeating patterns + perfect shapes
- Sparse clinical typography (thin fonts preferred)
- Limited, intentional color palette
- Subtle reference embedded (only those who know will catch it)
- Every element inside canvas boundaries with proper margins

**Typography rules**:
- Minimal — integrated as visual element
- Different fonts per project (search canvas-fonts/)
- Can be art itself (hand-drawn, part of composition)
- NEVER paragraphs of text

**Refinement pass (always)**:
- Do not add more elements — refine existing
- Ask: "How does this become more of a piece of art?"
- Check: nothing overlaps, everything has breathing room
- Final: could be displayed in a museum

## Philosophy Examples

### "Concrete Poetry"
Communication through monumental form. Massive color blocks, sculptural typography. Polish poster energy meets Le Corbusier. Text as rare gesture.

### "Chromatic Language"
Color as information system. Geometric zones create meaning. Josef Albers meets data visualization. Words only anchor what color shows.

### "Analog Meditation"
Quiet contemplation through texture. Paper grain, ink bleeds, vast space. Japanese photobook aesthetic. Images breathe.

### "Geometric Silence"
Pure order and restraint. Grid precision, dramatic negative space. Swiss formalism meets Brutalist honesty. Structure communicates.

## Multi-Page (Coffee Table Book)
- Each page: same philosophy, distinctly different execution
- Pages tell a story tastefully
- Bundle as single PDF or multiple PNGs
- Treat page 1 as first chapter, not the whole book
