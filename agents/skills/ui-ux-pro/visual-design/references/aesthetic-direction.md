# Aesthetic Direction Reference

## How to Choose a Direction

1. What problem does this interface solve? (productivity, commerce, social, creative)
2. Who is the audience? (age, context, expertise)
3. What emotional state should they leave in?
4. What product does this most resemble — and how do we differentiate?

## Aesthetic Profiles

### Severe Minimalism
- Massive white/dark space
- One or two elements per view
- Typography does all visual work
- References: Linear, Stripe, Notion
- Fonts: Söhne, Instrument Sans, Literata

### Editorial / Magazine
- Strong typographic hierarchy
- Image-driven sections
- Headline as visual block
- References: Bloomberg, NYT, Are.na
- Fonts: Playfair Display, Cormorant, DM Serif Display

### Brutalist / Raw
- Exposed structure, visible grid
- High contrast, harsh edges
- No polish for polish's sake
- References: Figma old site, Gumroad
- Fonts: Space Mono, Courier, custom bold sans

### Luxury / Refined
- Generous whitespace, slow pace
- Thin strokes, restrained color
- Gold/cream/black palette typical
- References: SSENSE, Bottega, Net-a-Porter
- Fonts: Cormorant Garamond, Freight Display

### Retro-futuristic
- Neon + dark backgrounds
- Scan lines, CRT effects, grid
- References: Raycast, Vercel dark, Warp
- Fonts: JetBrains Mono, Syne, custom variable

### Organic / Natural
- Rounded, soft shapes
- Muted nature palette
- Hand-drawn elements acceptable
- References: Notion (warm), Superhuman, Linear (warm mode)
- Fonts: Plus Jakarta Sans, Nunito, Instrument Serif

### Glassmorphism / Spatial
- Frosted glass layers
- Depth through blur + shadow
- Background shows through
- Works best: dark backgrounds
- Fonts: SF Pro (iOS), Geist, clean sans

### Maximalist / Layered
- Dense information, rich texture
- Pattern, color, movement
- Every pixel purposeful
- References: Basement Studio, Calmly, Layers
- Fonts: Syne, Clash Display, Cabinet Grotesk

## Anti-Patterns by Type

### Layout Anti-Patterns
- Symmetric centered column (every AI default)
- Equal-weight two-column layouts
- Card grids with identical gutters and shadows
- Hero: centered text + button + mockup (pure template)

### Color Anti-Patterns
- Purple/indigo gradient on white
- Teal + coral everywhere
- "Playful" rainbow palettes with no hierarchy
- Background #F9FAFB with text #111 (zero character)

### Typography Anti-Patterns
- Inter for everything
- Bold heading + regular body, same type family
- No typographic surprise (all same weight, all similar size)
- Headlines that don't feel designed

## Differentiation Anchors

Pick ONE per project and own it completely:

| Anchor | What it means |
|---|---|
| Color | Unusual, ownable palette — not from the standard UI toolkit |
| Type | A single distinctive typeface used dramatically |
| Space | Radical whitespace or radical density |
| Motion | One signature animation that defines the product |
| Texture | Real material feel: grain, noise, paper, glass |
| Layout | Grid-breaking composition (diagonal, overlap, asymmetry) |
| Illustration | Consistent custom visual language |
