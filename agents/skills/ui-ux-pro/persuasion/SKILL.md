## Fogg Behavior Model

```
Behavior = Motivation × Ability × Prompt

Most UX failures: LOW Ability (friction) or WRONG Prompt (timing)
Fix: remove friction before adding more persuasion
```

## 5-Step Framework

1. **Define ONE target behavior** — be specific ("complete onboarding" not "engage more")
2. **Audit friction** — list every unnecessary decision, field, step, hesitation point
3. **Design default path** — easiest path = most helpful path
4. **Insert commitment points** — small yes-steps before the big ask
5. **Verify ethical guardrails** — guide, never trap

## Choice Architecture Rules

| Variable | Strategy |
|---|---|
| Complex task | Break into smaller steps; reduce working memory load |
| Simple task | Compress path; minimize interruption |
| High stakes | Add reassurance, proof, review step |
| Low readiness | Education + previews + soft prompts |
| High readiness | Direct action path only |
| Cognitive friction | Simplify decisions + language |
| Emotional friction | Social proof + reassurance |
| Physical friction | Improve layout, spacing, affordances |

## Loss Framing Rules

- Use ONLY when reference point supports it
- Minimum signal needed for action — calibrate intensity
- Make cost of inaction specific + near-term
- Real tradeoffs only — no invented panic
- Credible, not theatrical

## Ethical Guardrails (Hard Limits)

```
✅ Make the right path clearer
✅ Reduce unnecessary friction
✅ Use intelligent defaults
✅ Real scarcity / real deadlines only
❌ Dark patterns
❌ Fake urgency / fake scarcity
❌ Hidden opt-outs
❌ Guilt-based pressure
❌ Exploiting anxiety or FOMO artificially
```

## Anti-Patterns

```
❌ Adding more persuasion instead of removing friction
❌ Overloading screen with options (Hick's Law violation)
❌ Exit-blocking (no escape from funnel)
❌ Framing losses that aren't credible
❌ Consecutive commitment demands (pushy stacking)
```

## Output Format

Deliver:
1. Current friction audit (what slows users down)
2. Redesigned default path
3. Commitment sequence (with rationale)
4. Loss/gain framing recommendation
5. Ethical check: "Would this feel guiding or manipulative?"
