# Krono — Permissões do App

## Visão Geral

O Krono requer permissões específicas para funcionar como overlay flutuante. Esta referência detalha cada permissão.

---

## Permissões do Manifest

| Permissão | Necessária para | Tipo |
|-----------|----------------|------|
| `SYSTEM_ALERT_WINDOW` | Overlay sobre outros apps | Especial |
| `FOREGROUND_SERVICE` | Serviço em background | Normal |
| `FOREGROUND_SERVICE_SPECIAL_USE` | Timer como caso de uso especial | Normal |
| `POST_NOTIFICATIONS` | Notificação persistente (Android 13+) | Normal |
| `REQUEST_INSTALL_PACKAGES` | Instalação de APK de atualização | Normal |
| `INTERNET` | Verificação de atualizações | Normal |
| `RECEIVE_BOOT_COMPLETED` | Reiniciar serviço após reboot | Normal |
| `WAKE_LOCK` | Manter tela ligada | Normal |
| `VIBRATE` | Feedback vibratório | Normal |

---

## Permissão Especial: SYSTEM_ALERT_WINDOW

### O que é
Permite que o app desenhe sobre outros apps. Necessária para o overlay do cronômetro.

### Como solicitar
1. Primeiro uso: abre `PermissionsDialog` guiar o usuário
2. redireciona para `Settings > Apps > Krono > Permitere sobre outros apps`
3. Retorna ao app após concessão

### Verificação no código
```kotlin
Settings.canDrawOverlays(context)
```

---

## Permissões de Notificação

### POST_NOTIFICATIONS (Android 13+)
- Necessária para a notificação persistente do cronômetro
- Solicita via `ActivityResultContracts.RequestPermission`

### FOREGROUND_SERVICE
- Mantém o serviço rodando quando o app está em background
- Essencial para o cronômetro não pausar

### FOREGROUND_SERVICE_SPECIAL_USE
- Define o serviço como "tipo" especial para uso contínuo
- Melhora a优先级 do sistema para o serviço

---

## Fluxo de Solicitações

```
1. Primeira abertura do app
   ↓
2. Verifica SYSTEM_ALERT_WINDOW
   ├── Não concedida → PermissionsDialog → Settings
   └── Concedida → Continua
   ↓
3. Verifica POST_NOTIFICATIONS (Android 13+)
   ├── Não concedida → Solicita permissão
   └── Concedida/Não aplicável → Continua
   ↓
4. Inicia MainService ou MainActivity
```

---

## Tratamento de Erros

| Cenário | Ação |
|--------|------|
| Overlay negado | `PermissionsDialog`, não inicia overlay |
| Notificação negada | Funciona sem notificação |
|Boot incompleto | `BootReceiver` reinicia automaticamente |

---

## Referência de APIs

- **Overlay**: `WindowManager.addView()` com `TYPE_APPLICATION_OVERLAY`
- **Foreground Service**: `Context.startForegroundService()`
- **Permissões**: `ActivityResultContracts` e `Settings.canDrawOverlays()`
